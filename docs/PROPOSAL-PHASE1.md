# ระบบสั่งซื้อสำหรับดีลเลอร์ (เชื่อม Odoo) — แผน Phase 1 และใบเสนอราคา

วันที่: 21 ต.ค. 2026
สถานะ: ร่างเพื่อหารือ ราคาเป็นประมาณการ ยืนยันหลัง workshop สรุปขอบเขต 1 ครั้ง

---

## 1. สรุปสั้น

ระบบแบ่งเป็น 2 ส่วนที่ทำงานร่วมกัน

- **Odoo (ระบบหลังบ้านที่ใช้อยู่แล้ว)** ดูแลสินค้า สต็อก ใบสั่งขาย การจัดส่ง ใบแจ้งหนี้ และบัญชีเหมือนเดิม ทีมงานไม่ต้องเปลี่ยนวิธีทำงาน
- **เว็บแอปดีลเลอร์ (สร้างใหม่)** เป็นหน้าร้านให้ดีลเลอร์เข้ามาสั่งเองผ่านมือถือ และเป็นที่ตั้งค่า "ใครเห็นสินค้าอะไร ในราคาเท่าไร"

หลักที่ใช้แบ่ง: **อะไรเกี่ยวกับเงิน สต็อก และเอกสารบัญชี อยู่ใน Odoo** ส่วน **อะไรเกี่ยวกับประสบการณ์ของดีลเลอร์และสิทธิ์การมองเห็น อยู่ในเว็บ**
ทุกออเดอร์จากเว็บกลายเป็นใบสั่งขายใน Odoo ทันที ราคาและส่วนลดจึงตรงกับบัญชีเสมอ

```
ดีลเลอร์ (มือถือ) ──สั่งซื้อ──▶ เว็บแอป ──สร้างใบสั่งขาย──▶ Odoo ──▶ จัดของ / ส่งของ / ออกใบแจ้งหนี้
ดีลเลอร์ (มือถือ) ◀──สถานะ──── เว็บแอป ◀──แจ้งเมื่อมีการอัปเดต── Odoo
แอดมิน (เว็บ) ──ตั้งกลุ่มลูกค้า/กลุ่มราคา──▶ เว็บแอป ──ส่งราคาไปเป็น pricelist──▶ Odoo
```

## 2. ความต้องการแต่ละข้อ ทำที่ไหน

| # | ความต้องการ | ทำในเว็บ | ทำใน Odoo | เหตุผล |
|---|---|---|---|---|
| 1 | แบ่งกลุ่มลูกค้า ให้เห็นเฉพาะสินค้าที่เลือก | ✅ ตั้งกลุ่ม เลือกสินค้าตามหมวด/ยี่ห้อ/รายตัว ผูกดีลเลอร์เข้ากลุ่ม | ใช้ข้อมูลสินค้าและลูกค้าจาก Odoo | Odoo ไม่มีการซ่อนสินค้ารายลูกค้าสำหรับระบบภายนอก เว็บต้องกรองเองและบังคับที่ฝั่ง server (ดีลเลอร์แอบเปิดลิงก์สินค้านอกกลุ่มก็สั่งไม่ได้) |
| 2 | กลุ่มราคา ราคาต่างกันต่อสินค้า หลายกลุ่ม | ✅ หน้าตารางราคา (แบบ Excel) นำเข้าราคาเดิม อนุมัติ 2 ขั้นก่อนเผยแพร่ | ✅ เว็บส่งราคาที่อนุมัติแล้วไปเป็น pricelist ใน Odoo และผูกกับลูกค้า | แอดมินแก้ราคาที่เดียว แต่ใบสั่งขาย/ใบแจ้งหนี้ใน Odoo คิดราคาเดียวกับหน้าเว็บ ถ้ามีคนแก้จำนวนใน Odoo ทีหลัง ราคาก็ยังถูก ระบบตรวจทุกวันว่ามีใครแก้ราคาใน Odoo ตรงๆ หรือไม่ |
| 3 | ซื้อได้หลายหน่วย เช่น กล่อง / เส้น / มัด | หน้าเลือกหน่วยตอนใส่ตะกร้า แสดงราคาต่อหน่วยและจำนวนรวม | ✅ ตั้งหน่วยนับและอัตราแปลงที่สินค้า (เช่น 1 กล่อง = 4 เส้น) | สต็อกและบัญชีนับเป็นหน่วยเดียวใน Odoo เว็บแค่แปลงให้ดีลเลอร์เลือกง่าย ไม่มีตัวเลขสต็อกสองชุด |
| 4 | คูปอง / ส่วนลด | ช่องกรอกโค้ดตอน checkout แสดงยอดลดก่อนยืนยัน | ✅ สร้างและจัดการคูปอง/โปรโมชันในโมดูล Loyalty ของ Odoo (ติดตั้งแล้ว) | ส่วนลดออกเป็นบรรทัดในใบสั่งขายและใบแจ้งหนี้ ฝ่ายบัญชีเห็นครบ ไม่ต้องทำบัญชีส่วนลดแยก |
| 5 | ดีลเลอร์เห็นสถานะจัดส่ง/สถานะรายการ เมื่อ Odoo อัปเดต | ✅ หน้าติดตามออเดอร์ เป็น timeline (รอยืนยัน → กำลังจัดของ → ส่งแล้ว → ออกใบแจ้งหนี้ → ชำระแล้ว) | ✅ ตั้ง Automation Rule ให้ Odoo แจ้งเว็บทันทีเมื่อสถานะเปลี่ยน | ทีมคลัง/บัญชีทำงานใน Odoo ตามปกติ ดีลเลอร์เห็นเองโดยไม่ต้องโทรถาม มีระบบตรวจซ้ำทุก 5 นาทีกันการแจ้งตกหล่น |

งานที่จำเป็นต้องมีเพื่อให้ 5 ข้อใช้งานได้จริง (รวมในราคาแล้ว): login และสิทธิ์ผู้ใช้, แคตตาล็อกค้นหาตามขนาดยาง, ตะกร้าและ checkout, แนบสลิปโอนเงิน, หน้าแอดมินตรวจสลิปและยืนยันออเดอร์

## 3. สิ่งที่ทีมของลูกค้าทำต่อใน Odoo (ไม่เปลี่ยน)

- เพิ่ม/แก้สินค้า รูป ราคาทุน สต็อก — เว็บดึงไปแสดงเอง
- ยืนยันการจัดของและการส่งของ, ออกใบแจ้งหนี้, บันทึกรับชำระ
- สร้างคูปองและโปรโมชัน
- **ข้อตกลง 1 ข้อ:** pricelist ที่ชื่อขึ้นต้นด้วย `WEB |` ให้แก้จากเว็บเท่านั้น เพราะเว็บจะเขียนทับทุกครั้งที่เผยแพร่ราคา

## 6. สมมติฐานที่ราคานี้ใช้ (ถ้าไม่ตรง ราคาอาจปรับ)

1. "กลุ่มลูกค้า" กำหนดสินค้าที่เห็นได้ตามหมวด ยี่ห้อ หรือรายตัว และดีลเลอร์ 1 รายอยู่ได้ 1 กลุ่มลูกค้า + 1 กลุ่มราคา
2. จำนวนกลุ่มราคาไม่จำกัด แต่ละกลุ่มกำหนดราคารายสินค้า หรือ % จากกลุ่มอื่นทั้งหมวดได้
3. หน่วยนับ (กล่อง/เส้น/มัด) และอัตราแปลง ตั้งไว้ใน Odoo ราคาต่อหน่วยใหญ่คำนวณจากหน่วยเล็ก เว้นแต่จะกำหนดแยก
4. คูปองใช้ความสามารถของ Odoo Loyalty ที่มีอยู่ ไม่สร้างระบบคูปองใหม่ในเว็บ
5. 1 ร้านดีลเลอร์ = 1 ลูกค้าใน Odoo มีผู้ใช้หลายคนได้ โดยไม่ต้องซื้อ license Odoo เพิ่ม
6. ชำระเงินด้วยการโอนแล้วแนบสลิป แอดมินตรวจและยืนยันทุกออเดอร์

## 7. คำถามที่ต้องการคำตอบก่อนเซ็น spec

1. หน่วยที่ซื้อได้มีอะไรบ้าง (กล่อง / เส้น / มัด / อื่นๆ) และ 1 กล่อง 1 มัด เท่ากับกี่เส้นในแต่ละสินค้า
2. ดีลเลอร์ 1 รายอยู่ได้หลายกลุ่มลูกค้าไหม
3. คูปองแบบที่ใช้บ่อย: ลดเป็นบาท / ลดเป็น % / ซื้อครบได้ส่วนลด / ใช้ได้เฉพาะบางกลุ่มลูกค้า
4. ดีลเลอร์เห็นจำนวนสต็อกจริง เห็นแค่ "มี/หมด" หรือไม่เห็นเลย สั่งเกินสต็อกได้ไหม
5. ต้องการเลขพัสดุจากบริษัทขนส่งในหน้าติดตามไหม
6. ต้องมี LINE Login ตั้งแต่ Phase 1 ไหม
7. มีดีลเลอร์ที่ได้เครดิตเทอม (ไม่ต้องแนบสลิป) ไหม
