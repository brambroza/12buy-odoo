# ระบบสั่งซื้อดีลเลอร์ยาง (12buy) — Next.js 16 + Odoo

เว็บสั่งซื้อสำหรับร้านดีลเลอร์ยาง แบตเตอรี่ และกระทะล้อ ร้านค้นหาสินค้า เห็นราคาของร้านตัวเอง สั่งซื้อ และติดตามออเดอร์ได้จากมือถือ ทีมหลังบ้านตรวจและยืนยันออเดอร์ แล้วระบบส่งใบสั่งขาย (Sale Order) เข้า Odoo ให้อัตโนมัติ

```text
ดีลเลอร์สั่งในเว็บ ──▶ แอดมินตรวจสลิป/ยืนยัน ──▶ สร้าง SO ใน Odoo ──▶ คลังจัดส่ง / บัญชีวางบิล-รับเงินใน Odoo
                                                                     │
ดีลเลอร์เห็นสถานะในเว็บ ◀──────────── เว็บดึงสถานะกลับจาก Odoo ◀──────┘
```

**ข้อมูลอะไรอยู่ที่ไหน**

| อยู่ใน Odoo (ต้นฉบับ) | อยู่ในเว็บ (Supabase) |
| --- | --- |
| ลูกค้า (`res.partner`), สินค้า, รูป, สต็อก, ภาษี | บัญชีผู้ใช้และสิทธิ์, ข้อมูลร้าน (ประเภท/ระดับ/จังหวัด) |
| ใบสั่งขาย, การจัดส่ง, ใบแจ้งหนี้, การชำระเงิน | ตะกร้า, ออเดอร์จากเว็บ, สลิปโอนเงิน |
| pricelist เดิม, คูปอง (Discount & Loyalty), วงเงินเครดิต | โซนราคา, ตารางราคา, กลุ่มลูกค้า, ใบสมัคร, ประวัติการแก้ไข (AuditLog) |

## คู่มือดีลเลอร์

### 1. สมัครและเข้าสู่ระบบ

1. กรอกฟอร์ม "สมัครเป็นดีลเลอร์" ที่หน้าแรกของเว็บ ทีมขายจะติดต่อกลับเพื่อยืนยันร้าน
2. เมื่ออนุมัติแล้ว ร้านจะได้อีเมลและ **รหัสผ่านชั่วคราว** จากทีมงาน (ทาง LINE หรือโทร)
3. เข้า `/login` → ใส่อีเมลและรหัสชั่วคราว → ระบบบังคับให้ตั้งรหัสใหม่ทันที
4. ติ๊ก "จดจำฉันไว้" ถ้าใช้เครื่องตัวเอง (อยู่ในระบบได้ 30 วัน) ถ้าไม่ติ๊ก ปิดเบราว์เซอร์แล้วต้อง login ใหม่
5. ลืมรหัสผ่าน: กด "ลืมรหัสผ่าน" แล้วกรอกอีเมล ทีมงานจะรีเซ็ตและส่งรหัสชั่วคราวใหม่ให้ (ไม่มีอีเมลอัตโนมัติ)

ร้านที่ถูกระงับหรือยังรออนุมัติจะ login ไม่ได้ และหน้าจอจะบอกเหตุผล

> แนะนำ: เปิดเว็บในมือถือแล้วกด "เพิ่มไปยังหน้าจอหลัก" จะเปิดตรงที่หน้าสั่งซื้อเหมือนแอป

### 2. หาสินค้า

เมนูล่างจอ (มือถือ) หรือแถบบน (คอมพิวเตอร์) มี 5 เมนู: **หน้าแรก · ค้นหา · สั่งเร็ว · ตะกร้า · ออเดอร์**

- **ค้นหาด้วยขนาดยาง** พิมพ์เช่น `195/65R15` หรือ `1956515` ผลลัพธ์เรียงราคาถูกไปแพง แสดงเฉพาะประเภทสินค้าที่ร้านสั่งได้
- **ราคาที่เห็นคือราคาของร้านคุณ** (ตามโซนจังหวัดและระดับร้าน) และ **รวม VAT แล้ว** ยอดในตะกร้าคือยอดที่ต้องจ่ายจริง
- สินค้าบางตัวขายเป็น **มัด** ได้ (เช่น มัด 5 เส้น) เลือกหน่วยได้ที่การ์ดสินค้า ราคามัด = ราคาต่อเส้น × จำนวนในมัด
- สินค้าที่ขึ้น "สินค้าหมด" สั่งไม่ได้ (เว็บไม่รับสั่งจอง)
- หน้าแรกมีปุ่ม **สั่งซ้ำ** ออเดอร์เก่า และรายการสินค้าที่สั่งบ่อย

### 3. สั่งเร็ว (หลายรายการทีเดียว)

เมนู **สั่งเร็ว** วางรายการทีละบรรทัดรูปแบบ `ขนาด จำนวน` แล้วกดเพิ่มลงตะกร้า

```text
195/65R15 4
100/80-14 2มัด5      ← 2 มัด มัดละ 5 เส้น
265/70R16 2มัด       ← 2 มัด ขนาดมัดเล็กสุดที่มี
```

บรรทัดที่หาไม่เจอหรือสินค้าหมดจะถูกข้ามและแจ้งให้ทราบ

### 4. ตะกร้าและสั่งซื้อ

ตรวจรายการ แก้จำนวน แล้วกรอกในหน้าเดียวกัน:

- **ที่อยู่จัดส่ง** เลือก จังหวัด → อำเภอ → ตำบล รหัสไปรษณีย์ขึ้นเอง ติ๊ก "บันทึกเป็นที่อยู่หลัก" ได้
- **ขนส่ง** เลือกจากรายการ
- **วิธีชำระเงิน** (ร้านเครดิตเท่านั้นที่เห็นตัวเลือกนี้)
  - **เงินสด** โอนเงินแล้วแนบสลิป ร้านเครดิตที่เลือกจ่ายเงินสดจะได้ **ส่วนลดท้ายบิล** อัตโนมัติ
  - **เครดิต** ไม่ต้องแนบสลิป วางบิลตามเทอม
- **คูปอง** กรอกโค้ดส่วนลด (ถ้ามี) ระบบแสดงส่วนลดก่อนยืนยัน
- **เลขที่ PO ของร้าน / หมายเหตุ** (ไม่บังคับ)

ระบบจะไม่ให้กดสั่งซื้อถ้า:
- สั่งเกินจำนวนที่มีในสต็อก
- เลือกเครดิตแล้วยอดค้างชำระ + ยอดออเดอร์นี้ เกินวงเงินเครดิตของร้าน (ติดต่อเซลล์เพื่อขยายวงเงิน หรือเลือกจ่ายเงินสด)

### 5. ติดตามออเดอร์และแนบสลิป

เมนู **ออเดอร์** แสดงทุกออเดอร์ของร้าน (พนักงานทุกคนในร้านเห็นเหมือนกัน) สถานะมี 5 ขั้น:

```text
รอยืนยัน → กำลังจัดสินค้า → จัดส่งแล้ว → วางบิลแล้ว → ชำระแล้ว
```

- ออเดอร์เงินสด: กดเข้าออเดอร์ → **แนบสลิป** (รูปไม่เกิน 4 MB) ทีมงานจะยืนยันออเดอร์หลังตรวจสลิป
- เมื่อจัดส่งแล้วจะเห็นเลขพัสดุในหน้าออเดอร์
- ยกเลิกเองได้เฉพาะออเดอร์ที่ยัง "รอยืนยัน" หลังจากนั้นติดต่อทีมขาย
- สถานะอัปเดตจาก Odoo อัตโนมัติ (ประมาณทุก 5–10 นาที)

### 6. ข้อมูลร้าน (`/shop/account`)

- แก้ไขที่อยู่จัดส่งและเบอร์โทร
- เปลี่ยนรหัสผ่านของตัวเอง
- **เจ้าของร้าน** เพิ่มบัญชีพนักงาน และดูรายชื่อผู้ใช้ในร้านได้

## คู่มือแอดมิน

เข้าหลังบ้านที่ `/login` ด้วยบัญชีทีมงาน แล้วใช้เมนูด้านซ้าย

### เริ่มใช้งานครั้งแรก (ทำครั้งเดียว)

1. เปิด `/setup` สร้างผู้ดูแลระบบคนแรก (SUPER_ADMIN) หน้านี้ปิดตัวเองทันทีเมื่อมีผู้ใช้ในระบบแล้ว
2. **ผู้ใช้งานระบบ** (`/admin/users`) เพิ่มทีมงานตามบทบาท ระบบออกรหัสชั่วคราวให้ **แสดงครั้งเดียว** คัดลอกส่งให้เจ้าตัวทันที
3. **โซนราคา** (`/admin/zones`) จัดจังหวัดเข้าโซน (1 จังหวัดอยู่ได้ 1 โซน จังหวัดที่ไม่ได้เลือกเข้าโซนค่าเริ่มต้น)
4. **ตารางราคา** (`/admin/prices`) ตั้งราคาของแต่ละโซน × ระดับร้าน แล้วเผยแพร่ (ดูหัวข้อราคาด้านล่าง)
5. (ถ้าใช้) **กลุ่มลูกค้า** และ **คูปอง**

### งานประจำวัน: ออเดอร์จากเว็บ (`/admin/orders`)

ออเดอร์ใหม่เข้ามาที่ inbox นี้ ออเดอร์ที่ค้างเกิน 2 ชั่วโมงจะมีป้ายเตือน

| ขั้น | แอดมินทำอะไร | ระบบทำอะไร |
| --- | --- | --- |
| 1. รอยืนยัน | ออเดอร์เงินสด: เปิดสลิป → กด **ตรวจสลิปแล้ว** (ยังไม่ตรวจสลิปจะยืนยันไม่ได้) / ออเดอร์เครดิต: ข้ามได้ | — |
| 2. ยืนยัน | กด **ยืนยัน** | สร้างและยืนยัน SO ใน Odoo อัตโนมัติ (เลขอ้างอิง `WEB-…`) ราคาตามที่ร้านเห็นตอนสั่ง เซลล์ = เซลล์ประจำร้านใน Odoo |
| 3. จัดส่ง | คลังทำ Delivery ใน Odoo ตามปกติ แล้วใส่เลขพัสดุในเว็บ | ดึงสถานะจัดส่งกลับมา |
| 4. วางบิล / รับชำระ | บัญชีทำใน Odoo ตามปกติ | ดึงสถานะใบแจ้งหนี้และการชำระกลับมา |

- อยากเห็นสถานะล่าสุดทันที กด **ดึงสถานะจาก Odoo ตอนนี้**
- ยกเลิกออเดอร์ได้จากหน้านี้ระหว่าง "รอยืนยัน" หรือ "กำลังจัดสินค้า" (มีหน้าต่างยืนยัน) ถ้า SO ถูกสร้างใน Odoo แล้ว ให้ยกเลิก SO ใน Odoo ด้วย
- **กฎสำคัญ:** ห้ามแก้จำนวนหรือราคาใน SO ที่ขึ้นต้นด้วย `WEB-` ใน Odoo เพราะ Odoo อาจคำนวณราคาใหม่ไม่ตรงกับที่ร้านเห็น ถ้าต้องแก้ ให้ยกเลิกแล้วให้ร้านสั่งใหม่

### ใบสมัครดีลเลอร์ (`/admin/leads`)

1. ร้านสมัครจากหน้าแรก → เข้ามาเป็นใบสมัคร (ถ้าตั้ง webhook ไว้ ทีมขายจะได้แจ้งเตือนด้วย)
2. ทีมขายโทรคุย แล้วเปลี่ยนสถานะเป็น "ติดต่อแล้ว" หรือ "ไม่ผ่าน"
3. แอดมินกด **อนุมัติและสร้างร้าน** → ได้ร้านสถานะ ACTIVE และผูกหรือสร้างลูกค้าใน Odoo ให้

### ตั้งค่าร้าน (`/admin/dealers`)

| ตั้งค่า | มีผลอย่างไร |
| --- | --- |
| ประเภทสินค้า (ยางรถยนต์ / บรรทุก / มอเตอร์ไซค์ / แบตเตอรี่ / กระทะล้อ) | ร้านเห็นและสั่งได้เฉพาะประเภทที่ติ๊ก |
| ระดับร้าน S / M / L | เลือกตารางราคา |
| จังหวัด | กำหนดโซนราคา (ไม่เกี่ยวกับที่อยู่จัดส่ง) |
| ผูกลูกค้า Odoo | ต้องผูกก่อนจึงจะส่ง SO เข้า Odoo ได้ |
| ร้านเครดิต | เปิดตัวเลือกเครดิต/เงินสดตอนสั่ง และส่วนลดเงินสดท้ายบิล |
| สร้างบัญชี / รีเซ็ตรหัส | ออกบัญชี DEALER_OWNER หรือ DEALER_STAFF ให้ร้าน |
| ระงับร้าน | ร้าน login ไม่ได้ และถูกออกจากระบบทุกเครื่องทันที |
| **เปิดมุมมองดีลเลอร์** | เข้า `/shop` ในฐานะร้านนั้น 8 ชั่วโมง ใช้ตรวจว่าร้านเห็นราคา/สินค้าอะไร |

หน้านี้เตือนร้านที่ยังไม่มีเซลล์ประจำใน Odoo ให้ไปตั้งที่ลูกค้าใน Odoo

### ราคา: โซน × ระดับร้าน (`/admin/zones`, `/admin/prices`)

ร้านเห็นราคาตามลำดับนี้:

1. ตารางราคาของ **โซน × ระดับ** ที่เผยแพร่แล้ว (ราคาคงที่รายตัว ถ้าไม่มีใช้ ราคาฐาน + % ของประเภท)
2. ถ้าไม่มีตารางที่เผยแพร่ ใช้ pricelist ของลูกค้าใน Odoo

ขั้นตอนตั้งราคา:

1. **นำเข้า** ราคาตั้งต้นจาก pricelist เดิมใน Odoo
2. ตั้ง % ต่อประเภทสินค้า และ/หรือ กรอกราคาคงที่รายตัว
3. กด **Dry run** ดูว่าจะเปลี่ยนอะไรใน Odoo บ้าง
4. **ส่งอนุมัติ** → **ผู้อนุมัติต้องเป็นคนละคนกับผู้ส่ง** → **เผยแพร่** (ระบบเขียน pricelist ชื่อ `WEB | โซน | ระดับ` ลง Odoo)

ส่วนลดเงินสดของร้านเครดิต: จับคู่ pricelist เครดิต ↔ เงินสด ในหน้าตารางราคา ส่วนลดต่อชิ้น = ราคาเครดิต − ราคาเงินสด รวมเป็นส่วนลดท้ายบิล

### กลุ่มลูกค้า (`/admin/groups`)

จำกัดสินค้าที่ร้านมองเห็น ร้านหนึ่งอยู่ได้ 1 กลุ่ม สินค้าที่เห็น = ประเภทของร้าน ∩ (ยี่ห้อ / หมวด / รายการที่เพิ่ม) − รายการที่ตัดออก กลุ่มที่ไม่ได้ตั้งเงื่อนไขอะไร = เห็นทุกสินค้า

### คูปอง (`/admin/coupons`)

สร้างและแก้คูปองใน **Odoo → Sales → Discount & Loyalty** หน้านี้แสดงโปรแกรมที่มีและบอกว่าใช้บนเว็บได้หรือไม่

- ใช้ได้: โปรแกรมแบบกรอกโค้ด ที่มีรางวัลเป็นส่วนลด 1 แบบ (% / บาท / ทั้งบิล / เฉพาะสินค้า / ขั้นต่ำ / ช่วงวันที่ / เฉพาะลูกค้า)
- ยังไม่รองรับ: แถมสินค้า, ส่งฟรี, หลายรางวัลให้เลือก

### ผู้ใช้และรหัสผ่าน (`/admin/users`)

- เพิ่ม / ปิดใช้งานทีมงาน, รีเซ็ตรหัส (ได้รหัสชั่วคราวใหม่ ผู้ใช้ต้องตั้งรหัสใหม่ตอน login)
- คำขอ "ลืมรหัสผ่าน" จากร้านและทีมงานจะแสดงที่หน้านี้ ตรวจตัวตนก่อน (เช่น โทรกลับเบอร์ร้าน) แล้วรีเซ็ตและส่งรหัสทาง LINE
- การเปลี่ยนแปลงสำคัญทุกอย่างบันทึกใน AuditLog

### เมนู "Odoo Sync (เดิม)"

`/dashboard`, `/sale-orders`, `/customers`, `/products` เป็นเครื่องมือจากเดโมรุ่นแรก (สร้างลูกค้า/สินค้า/ใบสั่งขายแล้ว sync เข้า Odoo) **ไม่ได้ใช้ในงานดีลเลอร์** อย่าใช้สร้างข้อมูลจริง ให้จัดการลูกค้าและสินค้าใน Odoo โดยตรง

## สำหรับนักพัฒนา

### สแตค

- Next.js 16 (App Router) + TypeScript + Tailwind v4 + shadcn/ui (Base UI)
- Supabase (Postgres) ผ่าน `@supabase/supabase-js` ฝั่ง server ด้วย service role key (`src/lib/db/`) ทุกตารางเปิด RLS โดยไม่มี policy จึงอ่านด้วย anon key ไม่ได้
- Migration อยู่ที่ `supabase/migrations` (Supabase CLI) เลิกใช้ Prisma ตั้งแต่ 2026-10-28 ของเก่าอยู่ที่ `archive/prisma-2026-10-28`
- Auth เขียนเอง: scrypt + ตาราง `Session` + cookie `sid` (httpOnly) ไม่ได้ใช้ Supabase Auth
- Odoo saas~19.4 ผ่าน JSON-RPC (`src/lib/odoo/rpc.ts`) ส่วน XML-RPC (`src/lib/odoo.ts`) ใช้เฉพาะเมนูเดิม

### ติดตั้ง

```bash
yarn install
cp .env.example .env.local     # ตั้ง SUPABASE_URL / SUPABASE_SERVICE_ROLE_KEY / ODOO_* / CRON_SECRET
supabase link --project-ref <ref>
supabase db push               # แจ้งทีมก่อนรัน migration กับ DB จริง
yarn dev                       # http://localhost:3000
```

ทดสอบการเชื่อมต่อ Odoo: `node scripts/test-odoo-auth.js` · unit test: `yarn test` · lint: `yarn lint`

### ตัวแปรสำคัญ

| ตัวแปร | ความหมาย |
| --- | --- |
| `ODOO_URL`, `ODOO_DB`, `ODOO_USERNAME`, `ODOO_API_KEY` | เชื่อม Odoo (staging: `tester12buy.odoo.com`) |
| `ODOO_READ_ONLY` | ค่าเริ่มต้น `true` = บล็อกการเขียน Odoo ทั้งหมด ต้องตั้ง `false` ชัดเจนถึงจะสร้าง SO / partner / pricelist ได้ |
| `CRON_SECRET` | สำหรับ `POST /api/cron/odoo-status` (header `Authorization: Bearer <secret>`, ยาวอย่างน้อย 16 ตัว) ตั้ง scheduler ให้เรียกทุก 5–10 นาที |
| `NEXT_PUBLIC_SITE_URL` | โดเมนจริง ใช้ทำ canonical / sitemap / OG ต้องตั้งก่อน deploy |
| `LEAD_WEBHOOK_URL` | (ไม่บังคับ) รับแจ้งเตือนใบสมัครใหม่และคำขอลืมรหัส เช่น relay ไป LINE |
| `SHOP_DEMO_CONTROLS` | `true` แสดงปุ่มเลื่อนสถานะเดโมให้หลังบ้าน **ห้ามเปิดบน production** |

### การป้องกันการเขียน Odoo

- `odooRead` อนุญาตเฉพาะ method อ่าน (`search_read`, `read`, `search_count`, …) method อื่น throw ก่อนยิง network
- `odooWrite` มี allow-list (เช่น `res.partner.create`, `sale.order.create`, `action_confirm`, loyalty wizard, pricelist) และทำงานเฉพาะเมื่อ `ODOO_READ_ONLY=false`
- request ต่อคิวทีละตัวและ retry เมื่อเจอ HTTP 429 (Odoo Online จำกัด burst)
- SO ใช้ `client_order_ref` = เลขออเดอร์เว็บ เพื่อกันการสร้างซ้ำ เลข PO ของร้านใส่ใน note

### ข้อจำกัดที่ยังมี

- ลืมรหัสผ่านยังต้องผ่านแอดมิน (ไม่มีอีเมลอัตโนมัติ); LINE ใช้เพื่อรับแจ้งเตือนเท่านั้น ยังไม่ใช้ login ด้วย LINE
- ใบกำกับภาษี PDF ดึงจากไฟล์แนบของใบแจ้งหนี้ใน Odoo จึงขึ้นหลังบัญชีกดพิมพ์/ส่งใบแจ้งหนี้แล้ว (ดีลเลอร์กด “ขอใบกำกับภาษี” แจ้งบัญชีได้)
- CSP ยังเป็นโหมด report-only จนกว่าจะตั้ง `CSP_ENFORCE=true`; Sentry ทำงานเมื่อตั้ง `SENTRY_DSN`
- หลังบ้านเพิ่ม: รายงานยอดขาย (`/admin/reports`), ประวัติการแก้ไข (`/admin/audit`), โปรโมชันหน้าแรก (`/admin/promotions`), ส่งออก CSV/Excel, bulk ยืนยัน/พิมพ์ใบจัดของ, ตั้งค่า LINE ใน `/admin/settings`; ดู `docs/RUNBOOK.md` สำหรับ deploy/backup/incident
- เลขพัสดุกรอกในเว็บ (Odoo ยังไม่ได้ติดตั้ง `stock_delivery`)
- คูปองและการเผยแพร่ pricelist เข้า Odoo ยังไม่ได้ทดสอบบน staging
- staging ใช้ Supabase ตัวเดียวกับ production แนะนำแยก
- เอกสารเพิ่มเติม: `docs/PLAN.md`, `docs/PROPOSAL-PHASE1.md`, คู่มือแอดมินและรายงาน UAT ใน `docs/`
- **สมัครดีลเลอร์**: ฟอร์มหน้าแรกเก็บชื่อร้าน ที่อยู่ครบ (จังหวัด → อำเภอ → ตำบล → รหัสไปรษณีย์) เบอร์ LINE หมวดสินค้า อีเมล รหัสผ่าน + ยืนยันรหัสผ่าน รหัสเก็บเป็น scrypt hash ใน `DealerLead.passwordHash` (migration `20261029150000_dealer_lead_account.sql`) ระหว่างรออนุมัติ login จะขึ้น "ใบสมัครอยู่ระหว่างตรวจสอบ" เมื่อแอดมินอนุมัติ ระบบสร้างร้าน (พร้อมที่อยู่จัดส่ง) และบัญชี `DEALER_OWNER` ด้วยรหัสที่ร้านตั้งเอง แล้วลบ hash ออกจากใบสมัคร (ไม่ผ่านก็ลบ) webhook แจ้งทีมขายไม่มีรหัสผ่าน
- **กันบอท**: Cloudflare Turnstile บนฟอร์มสมัคร ตั้ง `NEXT_PUBLIC_TURNSTILE_SITE_KEY` + `TURNSTILE_SECRET_KEY` (production ไม่มี secret = ปฏิเสธการสมัคร, dev ข้ามการตรวจ) ร่วมกับ honeypot และ rate limit 3 ครั้ง/ชม./IP
